# Checklists de domínio

Cada arquivo traz pontos típicos de um domínio de negócio, para ajudar a encontrar lacunas em requisitos.

| Arquivo | Domínio |
|---|---|
| `seguros.md` | Seguros (cotação, apólice, sinistro, cobrança) |

## Como adicionar um domínio

1. Crie `<dominio>.md` nesta pasta (ex.: `ecommerce.md`, `saude.md`, `bancario.md`).
2. Liste em checklist os pontos que costumam faltar nos requisitos desse domínio.
3. Abra um PR. As skills passam a usar o novo checklist automaticamente quando o requisito for desse domínio.

Regra: o checklist serve para fazer perguntas, nunca para inventar regras de negócio.
